# Control Mensajes Santa Cruz

Herramienta sencilla para la gestión y seguimiento de mensajes, llamadas telefonicas, correos, etc..

## Funcionalidades
- Registro de acciones y notas
- Interfaz ligera en HTML, CSS y JavaScript
- Uso local, sin dependencias externas
- Datos gestionados en local (no incluidos en el repositorio)

## Privacidad
Este repositorio contiene **solo código**.  
Los datos reales no se suben a GitHub.

## Uso
Abrir `index.html` con Live Server o directamente en el navegador.
